Ngay audit: 2026-09-26  
Pham vi: read-only `templates/`, `static/`, `core/`, `motel_management/` va giao dien public dang chay.  
Runtime files modified: NONE. Database changes: NONE. Migrations: NONE.

## Executive summary

NDT MOTEL da co nen tang giao dien kha day du, flow nghiep vu ro va nhan dien teal/vang nhat quan o cap thuong hieu. Cac trang public moi (`/phong/`, chi tiet phong, booking tenant) co responsive tot hon phan admin cu. Van de lon nhat truoc khi bao ve la no ky thuat giao dien: CSS/JS noi tuyen rat lon, typography admin qua nho, status/button/card duoc dinh nghia lai theo tung trang, va hai template con loi encoding that.

Browser audit read-only tren `/`, `/phong/`, `/phong/1/`, `/dang-nhap/`, `/dang-ky/` tai 1440, 1024, 768, 390 px:

- 20/20 lan tai HTTP 200, khong JS page error, khong horizontal overflow.
- Khong co anh broken tren cac trang public da kiem tra.
- Co 2-11 interactive target/trang nho hon nguong de xuat 44x44; auth mobile la nhom te nhat.
- Admin/tenant authenticated pages khong duoc browser-test vi audit khong tao session hay ghi DB. Cac trang nay duoc audit tinh tu template/CSS; can visual QA co tai khoan o phase trien khai.

## Recommended implementation phases

1. **Baseline:** screenshot regression, encoding tests, route/template ownership, token inventory freeze.
2. **P0 demo safety:** typography admin, responsive table shell, mojibake, critical confirms, raw statuses.
3. **Foundation:** tokens, buttons, forms, badges, page headers, focus/loading states.
4. **Workflow pages:** booking/payment/contract/tenant, then room/repair/extension/notification.
5. **Smart Room:** Face ID/access/entry history with shared modal and feedback patterns.
6. **Cleanup:** move inline CSS/JS, retire confirmed dead templates/code, final 4-viewport and role-based QA.
